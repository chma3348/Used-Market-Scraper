# Sold log

Fill a row in when something actually sells. This is the only place real
numbers ever enter the system — everything in [price-sheet.md](price-sheet.md)
is inferred from asking prices, because eBay put sold listings behind a login.
Each row you add here makes the next price sheet less of an estimate.

Worth recording even when it goes badly. A thing that sat for six weeks and
sold at half the ask is the most useful row on the page.

| Date listed | Item | Channel | Asked | **Sold for** | Days | Notes |
|---|---|---|---|---|---|---|
| | | | | | | |

### What to note

- **Channel** — eBay / Facebook / Craigslist / in person. The gap between them
  is the whole argument for the local column in the price sheet.
- **Days** — how long it sat. This is the number no price database has, and the
  one that tells you whether you priced it right. Sold in a day means you left
  money on the table; six weeks means you did not.
- **Notes** — what the buyer asked about, what you had to disclose, whether you
  took an offer. Patterns show up fast: if three buyers in a row ask whether the
  F3's LCD is clean, that belongs in the title, not the description.

### Fees actually paid

eBay takes 13.25% plus $0.40 on cameras and photo. If a sale comes in different
from that — a promoted-listing fee, an international sale, a discounted
shipping label — note it, because the price sheet's net column assumes the
standard rate.
